# Statistical Engineering & Simulation

## Project Overview
A pure-Python statistical engine built from scratch using only standard library modules. Processes 1D numerical data and demonstrates the Law of Large Numbers through Monte Carlo simulation.

## Mathematical Logic

### Variance Formula
- **Population Variance**: σ² = Σ(xᵢ - μ)² / N
- **Sample Variance** (Bessel's correction): s² = Σ(xᵢ - x̄)² / (n - 1)

### Median Constraint Handling
- **Odd list length**: Middle value at position (n+1)/2
- **Even list length**: Average of two middle values at positions n/2 and (n/2)+1
